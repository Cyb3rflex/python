# Module 6 — Operators

Operators are symbols used to perform operations.

## 6.1 Arithmetic Operators

| Operator | Description |
| :--- | :--- |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulus |
| `**` | Exponent |
| `//` | Floor division |

Example:

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)
```

---

## 6.2 Comparison Operators

| Operator | Description |
| :--- | :--- |
| `==` | Equal |
| `!=` | Not equal |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal |
| `<=` | Less than or equal |

Example:

```python
port = 443
print(port == 443)
```

**Output:**
```
True
```

## 6.3 Logical Operators

Python has:
- `and`
- `or`
- `not`

Example:

```python
username = "admin"
password = "1234"

if username == "admin" and password == "1234":
    print("Login successful")
```
