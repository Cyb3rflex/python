# Module 4 — Data Types

Python has several built-in data types.

Common types include:
- String
- Integer
- Float
- Boolean
- List
- Tuple
- Set
- Dictionary

---

## 4.1 Strings

Strings contain text.

```python
username = "admin"
```

Another example:

```python
message = "Welcome to cybersecurity"
```

Check the type:

```python
print(type(username))
```

---

## 4.2 Integers

Integers are whole numbers.

```python
port = 443
attempts = 5
```

---

## 4.3 Floats

Floats are numbers containing decimal values.

```python
temperature = 36.5
```

---

## 4.4 Booleans

Boolean values are `True` or `False`.

Example:

```python
is_logged_in = True
```

---

## 4.5 Checking Data Types

Use `type()`:

```python
username = "admin"
print(type(username))
```

**Output:**
```
<class 'str'>
```
